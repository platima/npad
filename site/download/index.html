Download

Download npad

Free and open source. Every release is published on GitHub. All three Windows downloads work for the current user with no admin rights, and the Linux repositories are signed.

Windows

Availablex64arm64

Installer

The recommended choice. Adds npad to your PATH and to “Open with”. File associations (text files ticked by default, the rest optional), the notepad alias (ticked by default) and the bundled fonts are choices in setup.

npad-v<version>-setup-win-x64.exe

Silent install: /VERYSILENT. For every account on the PC, choose it in setup or add /ALLUSERS; running setup as administrator on its own still installs for that one account.

Get the installer (opens in a new tab)

MSI

For managed and silent deployment.

msiexec /i npad-v<version>-msi-win-x64.msi /qn /norestart

Add ALLUSERS=1 for a machine-wide install. ADDLOCAL replaces the default set of features, so list every one you want (see the installation reference).

Get the MSI (opens in a new tab)

Portable

Download and run it from anywhere. No installation required.

npad-v<version>-portable-win-x64.exe
Get the portable .exe (opens in a new tab)

Choose the file for your PC on the release page. File names include the version number, so the button takes you to the latest release and its asset list. Pick -win-arm64 in place of -win-x64 for the native build on Windows on Arm (Snapdragon and other Arm laptops); the x64 build also runs there, under emulation. The in-app updater keeps each copy on its own architecture.

SmartScreen warning? Releases are code-signed (check Properties → Digital Signatures), but Microsoft SmartScreen builds a publisher’s reputation over time and may still warn. Right-click the downloaded file, choose Properties, tick Unblock and click Apply (or choose “More info” then “Run anyway”). To check the download first, compare the hash from Get-FileHash <file> in PowerShell (or certutil -hashfile <file> SHA256) with its line in CHECKSUMS.txt on the release page. Full details are in the installation reference (opens in a new tab).

Linux

Availablex86-64arm64riscv64

The GTK 3 desktop build, one binary for X11 and Wayland, has every feature of the Windows build: Preferences, the font picker, the optional Markdown tools, printing and Print Preview. It is in beta while it is tested on real desktops. Packages come for x86-64, 64-bit Arm (a Raspberry Pi on a 64-bit OS, Arm laptops and servers) and 64-bit RISC-V. Help > Check for Updates tells you when a new release is out and how to update the way you installed npad; it never installs anything itself, since updates arrive through apt, dnf or pacman with the rest of your system. Follow progress in LINUX_PORT.md (opens in a new tab).

apt (Debian, Ubuntu, Mint) Recommended

Debian 12 and 13, Ubuntu 22.04 and newer, Mint 21 and newer, LMDE (riscv64: Debian 13 and Ubuntu 24.04 or newer). The repository at pkg.npad.dev is signed with the npad packaging key, and npad then updates with the rest of your system.

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://pkg.npad.dev/npad.asc -o /etc/apt/keyrings/npad.asc
sudo curl -fsSL https://pkg.npad.dev/npad.sources -o /etc/apt/sources.list.d/npad.sources
sudo apt update && sudo apt install npad

Or let one script set up whichever of apt, dnf or pacman you have: curl -fsSL https://pkg.npad.dev/install.sh | sudo sh

dnf (Fedora)

The same signed repository serves the RPM:

sudo curl -fsSL https://pkg.npad.dev/npad.repo -o /etc/yum.repos.d/npad.repo
sudo dnf install npad

pacman (Arch Linux, Arch Linux ARM, Arch RISC-V)

The same signed repository serves a native Arch package for all three, and Arch derivatives such as Manjaro and EndeavourOS. pacman checks the database and the packages against the npad key, which you add and trust once:

curl -fsSL https://pkg.npad.dev/npad.asc -o /tmp/npad.asc
sudo pacman-key --add /tmp/npad.asc
sudo pacman-key --lsign-key "$(gpg --show-keys --with-colons /tmp/npad.asc | awk -F: '$1=="fpr"{print $10; exit}')"
printf '\n[npad]\nSigLevel = Required DatabaseRequired\nServer = https://pkg.npad.dev/arch/$arch\n' | sudo tee -a /etc/pacman.conf
sudo pacman -Sy npad

Portable tarball

For any glibc distro with GTK 3, including ones with no package: unpack and run ./npad. Its README.txt has the commands to add a menu entry under ~/.local. It is the same binary the packages install, and it does not update itself.

npad-v<version>-portable-linux-x86_64.tar.gz

Also -aarch64 and -riscv64.

.deb, .rpm and Arch packages

Every release also attaches the packages themselves: sudo apt install ./npad_<version>_amd64.deb, sudo dnf install ./npad-<version>-1.x86_64.rpm or sudo pacman -U ./npad-<version>-1-x86_64.pkg.tar.zst (and their arm64 / aarch64 and riscv64 builds). These do not update themselves.

Latest release (opens in a new tab)

Checking a download? In the folder you saved it to, with the release’s CHECKSUMS.txt beside it, run sha256sum -c --ignore-missing CHECKSUMS.txt. It checks just the files you downloaded.

Build from source

C99

npad is plain C on native platform APIs with no dependencies beyond system libraries. You need a C compiler and make; the Linux build also needs pkg-config and the GTK 3 development files.

git clone https://github.com/platima/npad.git
cd npad
make windows   # Windows x64 with MinGW-w64 (cross or native)
make linux-gtk # Linux GTK 3 build, produces ./npad-linux
make test      # unit tests

See the build instructions (opens in a new tab) and CONTRIBUTING.md (opens in a new tab).
