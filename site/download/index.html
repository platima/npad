Download

Download npad

Free and open source for Windows and Linux, on x64 and Arm. Every release is published on GitHub, and all three Windows downloads install for the current user with no admin rights.

Windows

Recommended

Installer

Adds npad to your PATH and to “Open with”. File associations (text files ticked by default, the rest optional), the notepad alias (ticked by default) and the bundled fonts are choices in setup. Silent install: /VERYSILENT

  • x64npad-v<version>-setup-win-x64.exe
  • arm64npad-v<version>-setup-win-arm64.exe Windows on Arm

Open the latest release (opens in a new tab)

File names include the version number, so the button takes you to the latest release and its asset list. Pick the file for your platform there.

MSI

For managed and silent deployment.

  • x64npad-v<version>-msi-win-x64.msi
  • arm64npad-v<version>-msi-win-arm64.msi
msiexec /i npad-v<version>-msi-win-x64.msi /qn

Add ALLUSERS=1 for a machine-wide install.

Portable

Download and run it from anywhere. No installation required.

  • x64npad-v<version>-portable-win-x64.exe
  • arm64npad-v<version>-portable-win-arm64.exe

SmartScreen warning? Releases are code-signed (check Properties → Digital Signatures), but Microsoft SmartScreen builds a publisher’s reputation over time and may still warn. Right-click the downloaded file, choose Properties, tick Unblock and click Apply (or choose “More info” then “Run anyway”). To check the download, compare its SHA-256 with CHECKSUMS.txt on the release page. Full details are in the installation reference (opens in a new tab).

Linux

The GTK 3 desktop build, one binary for X11 and Wayland, on amd64, arm64 and riscv64. There is no update checker on Linux by design: updates arrive through apt or dnf with the rest of your system. Follow progress in LINUX_PORT.md (opens in a new tab).

Quickest

Install in one step

Detects apt or dnf, adds the signed repository at pkg.npad.dev and its key, and installs npad.

Terminal
curl -fsSL https://pkg.npad.dev/install.sh | sudo sh

Add -s -- --repo-only after sh to add the repository without installing. Read the script (opens in a new tab) first if you prefer.

Or set it up yourself

apt Debian, Ubuntu, Mint

Debian 12 and 13, Ubuntu 22.04 and newer, Mint 21 and newer, LMDE.

Terminal
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://pkg.npad.dev/npad.asc \
  -o /etc/apt/keyrings/npad.asc
sudo curl -fsSL https://pkg.npad.dev/npad.sources \
  -o /etc/apt/sources.list.d/npad.sources
sudo apt update && sudo apt install npad

dnf Fedora

Terminal
sudo curl -fsSL https://pkg.npad.dev/npad.repo \
  -o /etc/yum.repos.d/npad.repo
sudo dnf install npad

apt and dnf pick your machine’s own architecture. riscv64 needs Debian 13, Ubuntu 24.04 or newer.

Or download a package

.deb Debian, Ubuntu, Mint

  • amd64npad_<version>_amd64.deb Debian 12, Ubuntu 22.04
  • arm64npad_<version>_arm64.deb Debian 12, Ubuntu 22.04
  • riscv64npad_<version>_riscv64.deb Debian 13, Ubuntu 24.04
sudo apt install ./npad_<version>_amd64.deb

.rpm Fedora

  • x86_64npad-<version>-1.x86_64.rpm
  • aarch64npad-<version>-1.aarch64.rpm
  • riscv64npad-<version>-1.riscv64.rpm
sudo dnf install ./npad-<version>-1.x86_64.rpm

Packages are attached to every GitHub release (opens in a new tab); file names include the version number. They do not update themselves. The oldest supported systems are Debian 12 and Ubuntu 22.04 (riscv64: Debian 13 and Ubuntu 24.04). Not sure which you need? dpkg --print-architecture or uname -m tells you.

Build from source

C99

npad is plain C on native platform APIs with no dependencies beyond system libraries. You need a C compiler and make; the Linux build also needs pkg-config and the GTK 3 development files.

git clone https://github.com/platima/npad.git
cd npad
make windows   # Windows x64 with MinGW-w64 (cross or native)
make linux-gtk # Linux GTK 3 build, produces ./npad-linux
make test      # unit tests

See the build instructions (opens in a new tab) and CONTRIBUTING.md (opens in a new tab).
