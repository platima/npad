Download

Download npad

Free and open source. Every release is published on GitHub, and all three Windows downloads install for the current user with no admin rights.

Windows

Availablex64

Installer

The recommended choice. Adds npad to your PATH and to “Open with”, with optional file associations, a notepad alias and bundled fonts.

npad-v<version>-setup-win-x64.exe

Silent install: /VERYSILENT

Get the installer

MSI

For managed and silent deployment.

msiexec /i npad-v<version>-msi-win-x64.msi /qn

Add ALLUSERS=1 for a machine-wide install.

Get the MSI

Portable

Download and run it from anywhere. No installation required.

npad-v<version>-portable-win-x64.exe
Get the portable .exe

Choose the file for your platform on the release page. File names include the version number, so the button takes you to the latest release and its asset list.

SmartScreen warning? Releases are code-signed (check Properties → Digital Signatures), but Microsoft SmartScreen builds a publisher’s reputation over time and may still warn. Right-click the downloaded file, choose Properties, tick Unblock and click Apply (or choose “More info” then “Run anyway”). To check the download, compare its SHA-256 with CHECKSUMS.txt on the release page. Full details are in the installation reference.

Linux

In progress

The GTK 3 desktop build (one binary for X11 and Wayland) has its foundation in v0.34.0: windows, menus, editing, open and save with encodings and line endings preserved, recent files, colour schemes and the status bar. Find / Replace, Preferences and printing are still being ported. Follow progress in LINUX_PORT.md.

apt (Debian, Ubuntu, Mint) Coming soon

A signed apt repository at pkg.npad.dev is being set up. This is the planned usage; the final commands will be confirmed here when it goes live.

curl -fsSL https://pkg.npad.dev/npad.gpg \
  | sudo tee /etc/apt/keyrings/npad.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/npad.gpg] https://pkg.npad.dev/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/npad.list
sudo apt update && sudo apt install npad

dnf (Fedora, RHEL) Coming soon

The same repository will serve RPMs. Planned usage:

sudo dnf config-manager addrepo \
  --from-repofile=https://pkg.npad.dev/rpm/npad.repo
sudo dnf install npad

.deb package Coming soon

A .deb will be attached to GitHub releases once the Linux packaging round lands.

Build from source

C99

npad is plain C on native platform APIs with no dependencies beyond system libraries. You need a C compiler and make; the Linux build also needs pkg-config and the GTK 3 development files.

git clone https://github.com/platima/npad.git
cd npad
make windows   # Windows x64 with MinGW-w64 (cross or native)
make linux     # Linux GTK 3 build, produces ./npad-linux
make test      # unit tests

See the build instructions and CONTRIBUTING.md.
