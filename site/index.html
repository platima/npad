npad

A fast, native, Notepad-faithful text editor.

Out of the box it behaves like Windows 10 Notepad. The extras (crash recovery, atomic saves, dark mode, printing with preview) never get in the way, and anything that changes how Notepad behaves is opt-in.

Download for Windows Linux (coming soon) View on GitHub

Free and open source (MIT). Windows installer, MSI and portable .exe, code-signed.

  • ~314 KBexecutable, 8 system libraries
  • ~3.4 MBRAM per window
  • ~40 msto a usable window
  • 0AI, telemetry or background services

Download

Every release is on GitHub. All three Windows downloads install for the current user by default and need no admin rights.

Windows

x64

Installer

npad-v<version>-setup-win-x64.exe

The interactive installer. Adds npad to your PATH, to the “Open with” menu, optional file associations and bundled fonts. Silent install: /VERYSILENT.

Get the installer

MSI

npad-v<version>-msi-win-x64.msi

For managed and silent deployment.

msiexec /i npad-v<version>-msi-win-x64.msi /qn

Add ALLUSERS=1 for a machine-wide install.

Get the MSI

Portable

npad-v<version>-portable-win-x64.exe

Download and run it from anywhere. No installation, nothing written to the registry.

Get the portable .exe

Build from source

C99

npad is plain C on native platform APIs, with no dependencies beyond system libraries. You need a C compiler and make; the Linux build also needs pkg-config and the GTK 3 development files.

git clone https://github.com/platima/npad.git
cd npad
make windows   # Windows x64 with MinGW-w64 (cross or native)
make linux     # Linux GTK 3 build, produces ./npad-linux
make test      # unit tests

See the build instructions and CONTRIBUTING.md.

Notepad, plus the parts you wish it had

npad has one rule for every feature: out of the box it behaves like Windows 10 Notepad. Enhancements that can’t hurt you are on. Anything that changes or could destroy that behaviour is off until you switch it on.

On by default

Non-destructive: crash recovery, the status bar, recent files, atomic saves.

Opt-in

Anything that changes how Notepad behaves: auto-save, following the system colour scheme, Markdown list tools, update checks, change-detection notices, word counts.

Safe by design

  • Crash recovery. Snapshots on the first edit, then every 30 seconds, offered back after a crash. They never touch your file.
  • Atomic saves. Written to a temporary file, verified, then renamed. A failed save can never destroy the existing file.
  • Encodings preserved. Detects and keeps UTF-8, UTF-8 BOM, UTF-16 LE/BE and ANSI. It warns before an ANSI save would lose characters.
  • Line endings preserved. CRLF, LF and CR are detected, shown in the status bar and convertible with a click (or Ctrl+E).
  • Large and binary file checks before opening, so you don’t freeze on a surprise.

Classic editing, quicker

  • Find and Replace with direction, match case, whole word, wrap-around, a live match count and optional highlight-all.
  • Go To Line, Time/Date (F5), word wrap (Alt+Z) and a 100,000-step undo history.
  • Status bar with Ln/Col, zoom, font mode, line ending and encoding. Click any of them to act on it.
  • Per-window zoom and font (Ctrl+Scroll, Ctrl+M), with monospace and proportional fonts chosen separately and an OpenDyslexic option.
  • Drag and drop to open; Ctrl+Drop inserts a file at the caret. A recent files menu, and separate windows via Ctrl+Shift+N.

Looks and printing

  • Light by default, like Notepad. Choose dark, follow the system, or Solarized Light / Dark; changes apply to every open window live.
  • The app icon follows your light or dark setting, or keep the classic one.
  • Printing and Page Setup with Notepad’s header and footer codes, printing the document rather than the window.
  • Print Preview (Ctrl+Shift+P) with paging, a two-page view and zoom, measured against your real printer so it wraps where the page does.

Optional extras (off by default)

  • Markdown list tools. Sort and unique lines, convert delimiters, indent and unindent with list markers, Enter to continue a list, cut line and paste above.
  • Rich-text paste. Turn HTML clipboard content into lists or Markdown. Plain-text clipboards always paste plain.
  • Auto-save, with a configurable interval.
  • Word, character and line counts in the status bar.
  • Update checks (off, notify, prompt or install), SHA-256 verified. npad never updates silently.
  • Notice when another program changes a file you have open, offering reload, save as or keep editing.

Windows integration

  • On your PATH, so npad file.txt works in any terminal.
  • In “Open with” for any file type, like notepad.exe, without taking over a type it doesn’t own.
  • Optional file associations in five groups (Text, Markdown, Data, Config, Logs), changeable later in Preferences.
  • Optional notepad alias for Win+R.
  • Settings as JSON, with export and import for backup or moving between machines.

Lean, on purpose

  • Native APIs, no frameworks. Win32 on Windows, GTK 3 on Linux.
  • One process per window, with memory cost that stays linear as you open more.
  • No background services. The only network call is an update check you have to turn on.

Why npad

The new Windows Notepad has grown slow, heavy and crowded with features nobody asked for, and it doesn’t seem to be possible to truly get the original back. There are plenty of great editors (Sublime Text, Notepad++, Neovim), and the author uses several of them, but none follow the design philosophy of notepad.exe.

npad is that philosophy, kept: open instantly, type, save, close. Then a short list of improvements that earn their place without changing how it feels.

What npad is not

  • No AI
  • No spellcheck
  • No syntax highlighting
  • No rich text
  • No frameworks
  • No forced or silent updates
  • No background services
