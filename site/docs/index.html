Command line

npad [options] [filename]
  -h, --help      Show help
  -v, --version   Show version

With npad on your PATH (the default in the installers), npad notes.txt works from any terminal. Typing npad in a File Explorer address bar opens an Open dialog in that folder.

Where things live

WhatWindowsLinux
Settings%APPDATA%\Platima\npad\settings.json~/.config/npad/settings.json

Preferences (Ctrl+,) has tabs for General, Appearance, Defaults, Markdown, Backup, Updates and Associations. Backup exports and imports your settings.
